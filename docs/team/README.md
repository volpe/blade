# Blade team design

The design is now implemented as shared instructions and four host packages.

- [Team workflow](../../team/workflow.md): applicable stages, responsibility coverage, collaboration, evidence, and approval policy.
- [Expert selection](../../team/expert-selection.md): proportionate staffing, charters, examples, and reassessment; reusable templates live in `team/roles/`.
- [Project profile](../../team/project-profile.md): reusable context and delivery record.
- [Codex](../../codex/README.md), [pi](../../pi/README.md), [Grok](../../grok/README.md), [Claude Code](../../claude/README.md): installation and actual communication capabilities.

Agreed defaults: reusable across projects; Deliver mode; guided checkpoints at applicable scope, design/approach, delivery, and release stages, with optional autonomous continuation; the coordinator reviews team effectiveness and can assign Team Steward for independent process review; reusable instruction changes require approval.

The main session coordinates and assigns outcome ownership to an appropriate expert or itself. Each expert has a task-specific purpose and viewpoint; there is no fixed team. Workers are scheduled as needed, with real messaging or an explicit coordinator relay. One writer owns a shared checkout, independent review remains separate, and sign-offs cover the current candidate. Installing the package does not create continuously running agents.

The earlier design walkthroughs were illustrative. See [validation notes](../validation.md) for the checks performed on the implementation and the remaining supervised trial.
