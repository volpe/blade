# Task-specific experts

Use the [expert-selection guide](../../team/expert-selection.md) to assemble a proportionate team. Every expert receives a purpose, viewpoint, questions, evidence requirements, and decision boundary tied to the actual task.

The [responsibility contract](../../team/workflow.md#expertise-and-responsibility) defines outcome ownership, production, verification, and independent review without a mandatory roster. Existing [role templates](../../team/roles/) are optional starting points; the generic [expert card](../../team/roles/expert.md) supports new specialties. Store task charters in the run record instead of editing the library. Reassess expertise as risks or evidence change.

Edit reusable instructions in the canonical sources, then run `npm run build` to update all four host packages. Steward proposals to change reusable instructions require user approval; routine staffing within authorized scope does not.
